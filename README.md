# DataSip – AI Powered Personalized Learning Platform

> An adaptive, interactive learning platform where students chat with an AI tutor, generate quizzes on any topic, and get personalized learning paths based on their performance.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🤖 AI Tutor Chat | Multi-turn conversations with Gemini, adapts to your level |
| 📝 Quiz Generator | MCQ & True/False quizzes on any topic, auto-graded |
| 🗺️ Learning Paths | Personalized step-by-step roadmaps generated by AI |
| 📊 Dashboard | Score trends, topic mastery charts, streak tracking |
| 🔐 Auth | JWT-secured accounts with learning profile |
| 🌙 Dark Mode | Full dark/light theme toggle |

---

## 🚀 Setup

### 1. Prerequisites
- Python 3.11+
- A Google Gemini API key (get one at [ai.google.dev](https://ai.google.dev))

### 2. Install dependencies
```bash
cd datasip
pip install -r requirements.txt
```

### 3. Configure environment
```bash
cp .env.example .env
# Edit .env and fill in your GEMINI_API_KEY and SECRET_KEY
```

### 4. Run the app
```bash
uvicorn backend.main:app --reload
```

The app will be available at **http://localhost:8000**

### 5. (Optional) Seed demo data
```bash
python -m backend.seed
```
Demo credentials: `demo@datasip.ai` / `demo1234`

## 📚 API Reference

### Authentication
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/register` | Create account |
| POST | `/api/auth/login` | Login, get JWT |
| GET | `/api/auth/me` | Get current user |
| PUT | `/api/auth/me` | Update profile |

### Chat
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/chat/message` | Send message to AI tutor |
| GET | `/api/chat/sessions` | List chat sessions |
| GET | `/api/chat/sessions/{id}` | Get session messages |
| DELETE | `/api/chat/sessions/{id}` | Delete session |

### Quiz
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/quiz/generate` | Generate AI quiz |
| GET | `/api/quiz/{id}` | Get quiz |
| POST | `/api/quiz/{id}/submit` | Submit answers |
| GET | `/api/quiz/history` | Quiz history |

### Learning
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/learning/path` | Generate learning path |
| GET | `/api/learning/path` | Get current path |
| PATCH | `/api/learning/path/{step_id}` | Mark step complete |
| GET | `/api/learning/recommendations` | Get recommendations |

### Dashboard
| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/dashboard/stats` | Get all stats |

## 🛠️ Tech Stack

- **Backend**: FastAPI + Uvicorn + SQLAlchemy (SQLite)
- **AI**: Google Gemini API (`gemini-2.5-flash`)
- **Auth**: JWT (python-jose) + bcrypt (passlib)
- **Frontend**: Vanilla HTML/CSS/JavaScript
- **Charts**: Chart.js (CDN)
